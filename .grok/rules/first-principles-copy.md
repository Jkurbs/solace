# First-principles copy

When writing or editing **any user-facing copy** (homepage, Hermes, dashboard, emails, errors, buttons, nav):

1. Read and follow **`notes/first-principles-copy.md`**.
2. Ban jargon and insider labels in chrome (Observatory, Anchor, Gates, posture, Era I) unless the audience is already inside that artifact.
3. Delete ~50% of the words. No slogans, no talking-down (“computer tools,” “crazy times”), no filler.
4. Concrete facts and measured specs only — never “smart,” “institutional,” or “ultra-secure.”
5. Say the mechanism: input → decision → what the user can do now.
6. Errors state cause + constraint + exact next action. Never “something went wrong.”
7. Litmus: strictly true? any word removable? mechanical outcome obvious before click?
8. Empathy still applies: honesty is care; empty and waiting states stay human.
