# Five-step algorithm — UI and product design

When working on **any Solace/Hermes UI** (marketing site, dashboard, onboarding, forms, nav):

1. Read and follow **`notes/five-step-algorithm.md`**.
2. Order is mandatory: question requirements → delete → simplify → speed up → automate last.
3. Every field, screen, and nav item needs a named owner and a user problem. “Best practice” and “what other products do” are not reasons.
4. If you did not delete enough to want ~10% back, delete more.
5. Do not polish or automate a flow that should not exist.
6. After deletion, still satisfy **`notes/user-experience-empathy.md`**: one fear, one answer; never present infra failure as user rejection.
